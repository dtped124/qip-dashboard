QIP 監測系統 探路包 使用說明
==============================

這是什麼
--------
品管中心想做一個「解壓縮就能用」的測試版，讓同仁在自己的電腦上試用。
在正式製作之前，需要先確認：您的電腦能不能執行其中幾個小程式。
這個探路包只做一件事：自動試跑並把結果記在一個文字檔裡。
它不會安裝任何東西、不需要管理員權限、不會連到網路、不會讀取任何院內資料。

怎麼做（約 2 分鐘）
------------------
1. 把 qip-probe-xxxxxxxx.zip 解壓縮到「C:\qip-probe\」。
   - 請直接放在 C 槽根目錄下。
   - 不要放在桌面、文件、下載或 OneDrive 資料夾（路徑太長、含中文或被同步，容易出錯）。
   - 解壓縮完成後，C:\qip-probe\ 裡面應該直接看到 probe.bat 與 runtime 資料夾。
     若多了一層 qip-probe\qip-probe\，請把裡面那一層移出來。
2. 在 C:\qip-probe\ 裡雙擊「probe.bat」。
3. 會跳出一個黑色視窗並自動執行，約需 10～60 秒。
   請不要關閉視窗，等到畫面出現「DONE」與「Press any key to continue」。
   - 若出現 Windows 或防毒軟體的警告／「已被封鎖」之類的訊息，
     請「不要」勉強放行，直接拍照或截圖，並照常繼續（這正是我們要知道的結果）。
4. 按任意鍵關閉視窗。
5. 把同資料夾裡的「probe-result.txt」寄回（或交給）品管中心。
   若 probe-result.txt 沒有產生，請把視窗畫面截圖給我們。

注意事項
--------
- 整個過程不會安裝任何東西，也不需要管理員權限；所有檔案只會寫在 C:\qip-probe\ 之內。
- 測試時會暫時在本機（只限本機，127.0.0.1）啟動一個資料庫，結束時自動關閉並刪除。
- 結果檔只含電腦名稱、使用者名稱、系統版本、各步驟成功或失敗，沒有任何院內資料。
- 測完之後，可以直接刪除整個 C:\qip-probe\ 資料夾，電腦不會留下任何東西。
- 若想再測一次，直接再雙擊 probe.bat 即可（結果會接在 probe-result.txt 後面）。

結果怎麼看（給品管中心）
------------------------
probe-result.txt 最後的 SUMMARY 有三行：
  1. PYTHON         內建 Python 能不能執行
  2. PYTHON_IMPORTS Python 能不能載入含編譯的套件（numpy、psycopg、ldap3）
  3. POSTGRESQL     可攜版 PostgreSQL 能不能建立、啟動、查詢、停止
檔案上方另列：是否管理員、系統是否已有 VC++ 執行階段（msvcp140.dll）。

有任何問題請洽品管中心。
